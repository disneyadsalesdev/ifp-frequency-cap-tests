# ET Anthropic Help Bot — Quick Start (1 page)

**What it is:** A Teams chatbot that answers questions using our SharePoint training docs and templates.

**Where:** Microsoft Teams → your team channel → **ET Anthropic Help Bot** (or Copilot → Agents)

---

## How to ask

1. Open the bot in Teams or `@ET Anthropic Help Bot` in your channel.
2. Type a plain English question.
3. Check the answer — verify file names and links before sharing externally.

---

## Example prompts

| You want… | Ask… |
|-----------|------|
| Training deck | "Where is the Cursor training guide?" |
| Claude access | "How do I get access to the Claude enterprise portal?" |
| Daily report | "What's the MSTR daily report workflow?" |
| Excel / HTML tips | "How do I use Claude to create HTML instead of Excel?" |
| Copilot setup | "How do we set up Copilot agents for Teams and SharePoint?" |
| Find a file | "Which SharePoint folder has the IFP forecast templates?" |

---

## What it can and can't do

| Can | Can't |
|-----|-------|
| Find docs and folders you have access to | Grant licenses or IT permissions |
| Summarize indexed training content | Access confidential or non-indexed libraries |
| Suggest next steps from our guides | Replace official policy or security approvals |

---

## If the bot can't help

1. Browse the [ET Anthropic SharePoint site](https://twdc.sharepoint.com/sites/ETAnthropic)
2. Ask in **#ai-training** (or your team channel)
3. Contact IT for access issues
